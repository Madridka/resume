# Резюме frontend-разработчика

Одностраничное резюме на Vue 3, TypeScript и Tailwind CSS 4. Компоненты используют Composition API и `<script setup>`, сборка настроена через Vite 7. Требование к среде разработки: Node.js 22.12 или новее.

## Структура

- `src/data/resume.ts` — содержимое резюме: контакты, навыки, опыт, проекты и образование.
- `src/types/resume.ts` — типы данных резюме.
- `src/components/resume/` — отдельные разделы страницы.
- `src/App.vue` — композиция страницы.
- `src/main.css` — подключение Tailwind, глобальные базовые правила и стили печати A4. Оформление и адаптивная вёрстка заданы utility-классами в компонентах.
- `photo/photo.png` — исходная фотография. Компонент шапки импортирует ее напрямую, поэтому Vite учитывает фотографию при сборке и формирует корректный путь к файлу.

TypeScript работает в строгом режиме. Алиас `@` соответствует каталогу `src`. Tailwind подключен официальным плагином `@tailwindcss/vite`; отдельная конфигурация PostCSS не требуется.

## Публикация и печать

Единственная точка входа приложения — `index.html`. Относительный `base: './'` позволяет размещать готовый каталог `dist` как в корне статического сайта, так и в подпапке, включая GitHub Pages.

Кнопка печати использует системный диалог браузера, где резюме можно сохранить в PDF. Стили печати адаптируют содержание к бумажной странице и скрывают управляющие элементы.

Публикация выполняется workflow `.github/workflows/deploy.yml` после каждого push в ветку `main`. В настройках репозитория GitHub для Pages источником публикации должен быть выбран **GitHub Actions**.
